# 阶段零兼容夹具

全部为 synthetic 数据，不含用户配置、真实工作区或密钥。路径按相对字符串保存，仅测试解码和内容顺序，不要求相应文件真实存在。

| 夹具 | 保护的读取契约 |
| --- | --- |
| session-minimal.json | 旧格式缺失字段继续采用当前默认值 |
| session-split.json | 分屏比例、标签顺序、活动项、终端分组/宽度/目录/用途解码和 round-trip |
| settings.jsonc | 注释、尾逗号、有效值、无效布尔值和项目白名单 |
| keymap.jsonc | 动作名、参数、null、Vim keys、注释及部分错误不影响有效绑定 |

对应测试在 src/editor/phase0_baseline.rs，以 phase0_ 前缀命名。普通测试仅调用现有解码接口，不写用户文件；磁盘恢复、配置文本修改和事件导航仍由已有测试覆盖。格式升级时保留这批旧格式输入，不为了迁移方便直接更新夹具为新格式。
