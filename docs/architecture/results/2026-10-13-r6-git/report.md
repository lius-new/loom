## 已完成

- 纯类型、解析、diff 文档、快照、模型与操作数据归 feature；进程服务归 infrastructure。
- `app/git`、`git_tasks`、`git_poll` 负责操作、后台写任务、目标校验与扫描发布。
- 八个 Git 视图归 `ui/git`，通过 Git 面板投影、只读快照、帧输入与语义命令工作。
  UI 不再访问根状态、应用命令或 Git 服务，输入框使用投影输入接口。
- app 负责文件打开/拖放、chrome、剪贴板、键盘接线、hunk 加载与克隆事务。
  diff 编辑器的 Git 操作改为命令；文档/窗格组合仍登记到 R8。
- 关闭 Git 迁移例外、根状态 UI 适配器与旧 runtime 桥接；不保留旧路径别名。

[performance.csv](performance.csv)。R5 没有相同脚本的本机可比常规数据，本轮建立 R6 记录。
